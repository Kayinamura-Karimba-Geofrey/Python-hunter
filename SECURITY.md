# Security Policy

## Reporting Security Vulnerabilities

The Python Hunter team takes the security of our platform and scannable environments seriously.

If you discover a security vulnerability within Python Hunter itself, please **DO NOT** open a public GitHub issue.

Instead, please report vulnerabilities privately via email to:

`security@python-hunter.internal`

### Information to Include

* Type of issue (e.g., path traversal, memory exhaustion, authorization bypass).
* Step-by-step instructions or proof-of-concept repository to reproduce the issue.
* Potential impact of the vulnerability.

We aim to acknowledge reports within 24 hours and issue fixes promptly.
